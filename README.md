# Kit-Drum
⇝Este proyecto es una batería virtual que combina elementos visuales y sonoros. Algunas características clave son:

✦Tecnologías Utilizadas✦

-HTML: Se utiliza para estructurar la interfaz de la batería virtual, definiendo las teclas y su disposición en pantalla.  
-CSS: Permite dar estilo al diseño visual de la batería, como colores, tamaños y efectos.  
-JavaScript: La lógica de reproducción de sonidos se implementa mediante JavaScript. Cada vez que se presiona una tecla en la pantalla, se reproduce el sonido correspondiente a una parte de la batería (como el bombo, la caja, los platillos, etc.).

En resumen, este proyecto ofrece una experiencia interactiva y divertida para los usuarios interesados en explorar los sonidos de una batería sin necesidad de tener una física a mano.
